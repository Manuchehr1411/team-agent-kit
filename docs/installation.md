# Установка в ChatGPT, Codex и Claude Code

Подготовлен пакет `plugins/team-agent-kit`, версия 0.2.3. Обе роли, четыре скилла, стандарты и учебные профили находятся внутри него. Публикация репозитория и включение плагина в аккаунте — отдельные действия пользователя.

## Codex: установка для своего аккаунта

Из корня полученной копии репозитория:

```text
codex plugin marketplace add .
codex plugin add team-agent-kit@team-agent-kit
```

После загрузки файлов в созданный публичный GitHub-репозиторий первая команда для удалённой установки будет такой:

```text
codex plugin marketplace add https://github.com/Manuchehr1411/team-agent-kit.git
```

Поддержка команды add проверена по справке локального Codex; для клиента без этой команды используй доступный каталог Plugins в приложении. Устройство repo marketplace описано в [официальном руководстве](https://developers.openai.com/plugins/build/plugins).

После установки начни новую сессию в нужном рабочем каталоге. Выбери установленный навык через `$`; если клиент показывает пространство имён плагина, выбирай именно запись Team Agent Kit. Скиллы из исходного `.agents/skills` этой библиотеки также видны при работе в её репозитории, поэтому для проверки установки удобен отдельный рабочий каталог.

Фрагмент [codex-config.example.toml](../packaging/codex-config.example.toml) можно объединить с пользовательским `~/.codex/config.toml`. Не заменяй им целиком существующие настройки. Тот же фрагмент в проектном `.codex/config.toml` применяется только к доверенному проекту и не заменяет установку. Роли и профили YAML библиотеки не являются настройками аккаунта Codex.

## Claude Code: установка для своего аккаунта

Из корня полученной копии:

```text
claude plugin marketplace add .
claude plugin install team-agent-kit@team-agent-kit
```

После загрузки файлов в GitHub для удалённого каталога используй:

```text
claude plugin marketplace add https://github.com/Manuchehr1411/team-agent-kit.git
```

После установки начни новую сессию и используй:

```text
/team-agent-kit:describe-task
/team-agent-kit:decompose-task
/team-agent-kit:define-dor-dod
/team-agent-kit:review-task
```

В запросе укажи роль и свои источники. При необходимости фрагмент [claude-settings.example.json](../packaging/claude-settings.example.json) объединяется с `~/.claude/settings.json`; он включает уже установленный плагин, но не загружает его сам. [Официальные команды установки](https://code.claude.com/docs/en/plugin-marketplaces).

## ChatGPT

Для локальной проверки в поддерживаемом настольном клиенте открой этот репозиторий и каталог Plugins: repo marketplace находится в `.agents/plugins/marketplace.json`. Установи из него Team Agent Kit и выбери навык через `@`. Это локальная проверка пакета, она не делает плагин общедоступным во всех аккаунтах и веб-клиентах.

Для команды администратор рабочего пространства с доступной функцией импорта открывает **Admin → Plugins → Add → Import marketplace**. Source: `https://github.com/Manuchehr1411/team-agent-kit`, Path — пустой, ветка — main. После импорта нужно проверить результат и назначить доступ нужным ролям. Обновления импортируются из GitHub; вручную — через Marketplaces → Sync now. Это распространение в границах рабочего пространства. [Официальная инструкция](https://learn.chatgpt.com/docs/enterprise/plugin-management).

Пошаговые инструкции для каждого клиента находятся на [странице установки](https://manuchehr1411.github.io/team-agent-kit/install/).

Публичная подача текущего skills-only пакета сейчас не подтверждена: пользователь получил от портала сообщение о прекращении приёма таких заявок. Состояние и незаполненные поля перечислены в [publication-status.md](publication-status.md). Локальный marketplace и публичный каталог OpenAI — разные каналы распространения.

Если подходящий канал подачи станет доступен:

1. Собери ZIP командой ниже и проверь его локально.
2. В портале публикации выбери свою подтверждённую личность издателя и загрузи `dist/team-agent-kit-0.2.3.zip`, если выбранный канал допускает такой пакет.
3. Заполни запрошенные сведения листинга, устрани результаты проверок и отправь пакет на рассмотрение.
4. После одобрения выполни публикацию; пользователи устанавливают плагин в своих аккаунтах через каталог.

Этот порядок и требования к издателю описаны в [официальной инструкции публикации](https://developers.openai.com/plugins/deploy/submission). Название Team Agent Kit в манифестах — название проекта, оно не заменяет подтверждение издателя в портале. Для аккаунта ChatGPT нет поставляемого нами YAML, который автоматически устанавливает плагин.

Пакет не содержит MCP-сервер, hooks или ключи. По текущим правилам портала добавление MCP к уже существующему опубликованному skills-only плагину не поддерживается; если позже потребуется собственное MCP-подключение, сначала проверь путь его выпуска. Это не мешает использовать методику с инструментами, уже подключёнными самим пользователем.

## Сборка и обновление

Пользователь обновляет пакет по [инструкции для своего клиента](https://manuchehr1411.github.io/team-agent-kit/updates/). В Codex обнови Git-каталог командой `codex plugin marketplace upgrade team-agent-kit`, затем повтори `codex plugin add team-agent-kit@team-agent-kit` и начни новую сессию. В Claude Code обнови каталог через `claude plugin marketplace update team-agent-kit`, затем выполни `claude plugin update team-agent-kit@team-agent-kit --scope user`, если пакет был установлен в user scope.

Готовые ZIP и SHA-256 публикуются в [GitHub Releases](https://github.com/Manuchehr1411/team-agent-kit/releases/latest). Архив самого плагина отличается от автоматически создаваемого GitHub архива исходного репозитория. Команды ниже предназначены для сопровождающих, которые меняют исходники и собирают пакет.

```text
python scripts/build_plugin.py
python scripts/build_plugin.py --check
python checks/validate.py
python checks/validate_distribution.py
python checks/test_listing_metadata.py
```

Нужен Python 3.10+, зависимости и сетевой доступ для сборки не нужны. Для отдельной проверки обязательных URL формы запусти `python checks/validate_distribution.py --submission`: в версии 0.2.3 все четыре адреса внесены. Этот режим не проверяет сетевую доступность страниц и возможность подачи. В среде с RTK добавляй `rtk proxy` перед shell-командами. Для повторной загрузки готового архива используй [resubmission.md](resubmission.md).

Исходники скиллов хранятся в `.agents/skills`, общие материалы — в `roles`, `standards`, `profiles` и `docs`. Манифесты, метаданные и инструкции установленного пакета редактируются в `packaging/`. Сборщик создаёт каталоги установки и дерево `plugins/team-agent-kit`, пересчитывает Markdown-ссылки и добавляет в каждый SKILL.md ссылку на инструкции пакета. Содержимое сохраняет общий источник истины; сгенерированные файлы вручную не редактируются.

Каталог `plugins/team-agent-kit` и оба marketplace.json должны попасть в репозиторий: тогда установка не требует запуска Python у пользователя. `dist/` игнорируется Git; ZIP можно приложить к релизу отдельно. В ZIP манифест `plugin.json` находится в корне, без внешней папки, а все ресурсы остаются внутри пакета. `bundle-manifest.json` — собственный список хешей библиотеки для контроля сборки, не настройка клиента.

При выпуске новой версии обнови её в обоих манифестах `packaging/`, внеси изменения в CHANGELOG и пересобери пакет. Для получения опубликованного обновления пользователь обновляет каталог/плагин средствами своего клиента. Изменение одного файла в репозитории не меняет уже установленную копию.

По поручению владельца библиотека распространяется по [MIT](../LICENSE); её применение объяснено в [licensing.md](licensing.md). Лицензия включена в ZIP, сведения об издателе и репозитории — в манифесты. Для распространения используется публичный репозиторий Manuchehr1411/team-agent-kit. Относительные пути каталогов не требуют корпоративного домена или личного пути. Порядок размещения информационного сайта — в [github-pages.md](github-pages.md).

## Проверка самим владельцем

В чистом рабочем каталоге после установки попроси описать задачу со своими требованиями, затем отдельно запусти ревью. Для проверки учебных кейсов явно выбери нужные профили. Убедись, что загружаются ресурсы из установленного пакета и не используются исходные авторские навыки из соседней рабочей области.

Проверка JSON, ссылок и сборки не заменяет пробу плагина в целевом аккаунте ChatGPT. Результаты доступных локальных проверок указаны в [distribution-results.md](../checks/distribution-results.md).
