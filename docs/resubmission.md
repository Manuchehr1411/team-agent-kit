# Повторная загрузка в ChatGPT / каталог OpenAI

Подготовлена версия 0.2.2. Используй `dist/team-agent-kit-0.2.2.zip`, созданный командой `python scripts/build_plugin.py`. Это ZIP самого плагина: plugin.json находится в корне, внутри есть четыре скилла, роли, общие ресурсы, LICENSE и пояснение лицензии на русском. Архив исходников из кнопки GitHub Download ZIP имеет другую структуру и не заменяет этот файл.

## Перед загрузкой

```text
python scripts/build_plugin.py --check
python checks/validate_distribution.py --submission
python checks/test_listing_metadata.py
```

Проверки локальные. Они сверяют пакет, обязательные метаданные, состав ZIP, ссылки и хеши; доступность внешних страниц и возможность подачи в конкретном аккаунте нужно проверять отдельно. В среде с RTK добавь `rtk proxy` перед командами.

Отображаемое имя в портале определяется выбранной подтверждённой личностью разработчика; публичный GitHub-логин не заменяет такую проверку. Документы сайта и фактический издатель подачи должны соответствовать друг другу.

## Загрузка

1. Открой существующий плагин в портале и выбери загрузку обновлённого пакета. Загрузи именно team-agent-kit-0.2.2.zip.
2. Проверь, что импортирована версия 0.2.2 и указаны все четыре URL. При ручном вводе используй значения выше.
3. Дождись проверки метаданных и скиллов. Если появятся новые ошибки, сохрани их точный текст для следующего исправления.
4. Выполняй подтверждение сведений, отправку на ревью и окончательную публикацию в своём аккаунте самостоятельно.

Полученное ранее сообщение `We are not accepting more skills-only submissions at this time` остаётся отдельным ограничением: новая лицензия, исправленные URL и ZIP не гарантируют приём заявки. Пакет не содержит MCP-сервера, и его нельзя описывать как MCP-плагин для обхода этого ограничения. Распространение через репозиторий и поддерживаемые локальные каталоги остаётся доступным.

Порядок повторной загрузки и проверка издателя: [официальная инструкция OpenAI](https://developers.openai.com/plugins/deploy/submission). [Текущий статус](publication-status.md).
