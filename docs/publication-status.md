# Статус подачи в публичный каталог OpenAI

Обновлено 2026-10-19. Пакет 0.2.1 пригоден для локальной установки через подготовленные каталоги. Готовность к публичной подаче не подтверждена.

## Сообщения портала

Пользователь передал результат проверки: privacy policy должна быть доступна; подзаголовок — не длиннее 30 символов; обязательны Website URL, Support URL, Privacy policy URL и Terms of service URL. Также портал сообщил: `We are not accepting more skills-only submissions at this time.`

Это наблюдение для текущей подачи пользователя, а не подтверждение одинакового доступа для всех организаций. Документация продолжает описывать skills-only путь; фактическое сообщение портала не позволяет считать его доступным в данном случае.

## Что исправлено

- Подзаголовок заменён на «Описание и проверка задач» — 25 символов с пробелами.
- Добавлена проверка ограничений метаданных, включая подзаголовок.
- Проверка `validate_distribution.py --submission` требует четыре URL из формы. Обычный режим проверяет локальную упаковку, где эти URL не обязательны.
- Версия повышена до 0.2.1, чтобы исправленную сборку можно было отличить от предыдущей.

## Что ещё требуется

| Поле формы | Поле манифеста | Необходимый результат |
| --- | --- | --- |
| Website URL | `extensions.com.openai.interface.websiteURL` | Опубликованная HTTPS-страница проекта |
| Support URL | `extensions.com.openai.interface.supportURL` | Доступная страница с реальным способом связи с издателем |
| Privacy policy URL | `extensions.com.openai.interface.privacyPolicyURL` | Опубликованная политика, соответствующая фактической обработке данных |
| Terms of service URL | `extensions.com.openai.interface.termsOfServiceURL` | Опубликованные условия использования от фактического издателя |

Публичные страницы пока не размещены. В манифест не добавляются локальные файлы или ещё не работающие адреса. После размещения нужно открыть страницы без авторизации, проверить HTTPS и содержание, затем пересобрать пакет. Синтаксическая проверка URL не доказывает их доступность.

Пользователь указал публичный GitHub-репозиторий Manuchehr1411/team-agent-kit. Подготовлен локальный сайт для GitHub Pages с планируемыми адресами всех четырёх страниц; [порядок размещения](github-pages.md). Pages ещё не опубликован и доступность адресов не подтверждена, поэтому поля манифеста пока не заполнены ими. Политика и условия сохраняют статус черновиков для проверки издателем.

Заполнение URL и исправление подзаголовка не снимает ограничение skills-only. Для текущей версии остаётся распространение через репозиторий/marketplace в поддерживаемых клиентах. Для публичного каталога нужно дождаться доступности подходящего канала либо отдельно разработать действительно необходимый MCP-сервис и проверить условия его подачи. Фиктивный MCP endpoint не добавляется; создание сервиса не входит в текущую работу.

Требования полей: [метаданные публикации](https://developers.openai.com/plugins/deploy/submission). Описание skills-only пути: [подача пакета со скиллами](https://developers.openai.com/plugins/guides/submit-claude-plugin). Эти инструкции не гарантируют доступность подачи в конкретной организации.
