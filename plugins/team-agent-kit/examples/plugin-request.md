# Первый запрос установленному плагину

Синтетический пример S9. В клиенте выбери установленный describe-task; в Claude Code можно начать с `/team-agent-kit:describe-task`.

```text
Роль business-analyst. Используй только общую методику, без командного
и проектного профиля. Подготовь описание по моим согласованным требованиям:
редактору нужно сосредоточиться на актуальных материалах.
BUNDLE-1: включение переключателя скрывает архивные материалы.
BUNDLE-2: выключение возвращает полный список.
Используется готовый переключатель; правила доступа не меняются.
Родителя и подзадач нет. Верни черновик в чате.
```

## Полученный результат

Контекст: business-analyst, describe-task; общая методика без командных и проектных дополнений.

### Скрытие архивных материалов

Цель — помочь редактору сосредоточиться на актуальных материалах.

Функциональные требования:

- BUNDLE-1: при включённом переключателе архивные материалы скрыты из списка.
- BUNDLE-2: при выключенном переключателе отображается полный доступный редактору список.

Границы: используется готовый переключатель; правила доступа не меняются. Источник — согласованное описание пользователя в S9; родителя и существующих подзадач нет. При подготовке не использовались требования учебных проектов, техническая реализация не задана.
