# Дополнения учебной команды

Все решения и данные в примерах синтетические. Этот стандарт действует для обоих учебных проектов и не описывает процессы реальной организации.

- TEAM-DOR-1: для блокирующего открытого вопроса указан владелец решения по роли или функции. Если владелец неизвестен, это отражается как недостающая информация. Не придумывай имя сотрудника.
- TEAM-DOD-1: итоговый артефакт содержит ссылки на использованные источники и оставшиеся ограничения; в учебных прогонах достаточно локальных относительных ссылок.

Другие условия берутся из [общего стандарта](../../../standards/dor-dod-baseline.md). Команда не требует отдельной задачи дизайна или тестирования для каждого изменения.
