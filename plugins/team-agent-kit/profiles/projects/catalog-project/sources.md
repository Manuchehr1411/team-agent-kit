# Источники учебного каталога

Синтетический источник `catalog-baseline`, версия 1. Внутри сценария S8 считается согласованным. Не использует требования списка заявок.

## Контекст и требования

Редактор просматривает каталог учебных материалов. Есть подтверждённый компонент выбора языка и готовые состояния таблицы; новый дизайн не требуется.

- CAT-1: при выборе языка «Русский» видны только материалы с языком «Русский».
- CAT-2: сброс выбора языка показывает все материалы каталога.

Фильтрация по статусу заявок, пользовательские роли операторов и API списка заявок сюда не переносятся. Правила доступа каталога не меняются. Для результата достаточно Markdown; трекер не используется.

## Дополнение к DoD

CAT-DOD-1: в передаваемом описании сохранены идентификаторы CAT-1 и CAT-2, чтобы редактор мог сопоставить результат с этим источником. Это условие передачи документа, а не дополнительная функция продукта.

Скилл `define-dor-dod` отключён по умолчанию для короткого описания в этом проекте. Его можно включить явным запросом. Это рекомендация выбора навыков, а не ограничение доступа к инструментам.
