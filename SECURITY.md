# Сообщения о безопасности

Для конфиденциального сообщения используй [Report a vulnerability](https://github.com/Manuchehr1411/team-agent-kit/security/advisories/new) в GitHub. Публичные Issues подходят для обычных ошибок; не размещай там секреты, закрытые документы и детали ещё не устранённой уязвимости.

Укажи версию пакета, затронутый файл или скилл, способ воспроизведения на синтетических данных и возможное влияние. Не прикладывай рабочие токены, пароли или реальные клиентские данные. Если приватная форма недоступна, создай общее обращение без чувствительных деталей с просьбой согласовать закрытый канал.

Основная поддерживаемая версия — последний стабильный GitHub Release. Исправления публикуются новой версией; старые установленные копии нужно обновить. Гарантированный срок ответа и исправления не заявлен.

Роли и списки навыков не ограничивают права инструментов. Доступ к источникам и возможность записи регулируются настройками клиента и подключённых сервисов. Текущий пакет не содержит собственного MCP-сервера или кода для приёма рабочих задач издателем.
