# Базовые DoR и DoD

Это общий стандарт. Командные дополнения лежат в профиле команды; проект уточняет применимость. Выбирай релевантные пункты, объясняй неприменимость и добавляй только условия, обусловленные задачей.

## DoR: подготовка к началу

| ID | Условие | Чем подтвердить |
| --- | --- | --- |
| DOR-1 | Понятны цель, границы и проверяемое поведение | Разделы основной задачи и источники |
| DOR-2 | Открытые решения, влияющие на начало выбранной работы, согласованы | Решение владельца либо явный блокер |
| DOR-3 | Существенные данные и внешние контракты доступны и применимы | Версия контракта, схема или согласованное описание |
| DOR-4 | Декомпозиция покрывает требования, нет дублирования и неопределённых блокирующих зависимостей | Карта покрытия и результаты зависимостей |
| DOR-5 | Понятно, как проверить результат; нужная среда и доступы определены | План проверки и подтверждение доступности, если она нужна для начала |

Готовность оценивай для указанной единицы работы: основной задачи, аналитики или разработки. Аналитика может быть готова, когда разработка ещё заблокирована отсутствующим контрактом.

## DoD: завершение работы

| ID | Условие | Чем подтвердить |
| --- | --- | --- |
| DOD-1 | Согласованный объём выполнен и изменения прошли применимое ревью | Артефакты и результат ревью |
| DOD-2 | Результат проверен в согласованном объёме, существенные дефекты устранены либо решение по ним зафиксировано | Результаты проверок и решения по дефектам |
| DOD-3 | Затронутые описания, контракты и эксплуатационные материалы обновлены, если изменилось их содержание | Ссылки на изменённые документы или обоснование неприменимости |
| DOD-4 | Результат передан потребителю работы; ограничения и оставшиеся работы видимы | Ссылка на передачу/артефакт и список ограничений |

DoD описывает условия завершения процесса. «Фильтр показывает только доступные записи» — функциональное требование/приёмка; «результат проверки фильтра приложен» — DoD. Не подменяй одно другим.

Для оценки каждого пункта используй `подтверждено`, `не выполнено`, `нет данных`, `неприменимо` и ссылку на доказательство или причину. Только заданный чек-лист имеет статус «условия сформированы, выполнение не проверено». Вывод «готово» допустим при подтверждении всех применимых условий; «нет данных» не равно успешной проверке.
