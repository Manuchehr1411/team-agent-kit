Обновление файлов в GitHub само по себе не меняет каждую установленную копию. Способ обновления зависит от того, как подключён пакет.

01 / CODEX

Обнови каталог и установку.

codex plugin marketplace upgrade team-agent-kit
codex plugin add team-agent-kit@team-agent-kit

Первая команда обновляет Git-источник marketplace, вторая устанавливает пакет из актуального каталога. Начни новую сессию и проверь версию Team Agent Kit в Plugins или выводе codex plugin list.

Если источник закреплён на конкретном commit или теге, он останется на выбранной ревизии. Для получения следующих изменений выбирай ветку main.

Управление marketplace в Codex

02 / CLAUDE CODE

Обнови источник и плагин.

claude plugin marketplace update team-agent-kit
claude plugin update team-agent-kit@team-agent-kit --scope user
claude plugin list

Команды соответствуют установке для своего пользователя из нашей инструкции. При другой области установки укажи её вместо user. Перезапусти сессию, чтобы применить новую версию.

Обновления Claude Code

03 / CHATGPT DESKTOP

Обнови локальную копию.

В терминале внутри склонированной папки team-agent-kit выполни:

git pull --ff-only

Перед этим сохрани свои незавершённые правки. Если Git сообщает о конфликте или расхождении веток, сохрани работу и разберись с причиной; инструкция не требует принудительного сброса файлов.

Перезапусти ChatGPT Desktop, открой Plugins и проверь версию. Если в установленной копии осталась старая версия, установи пакет заново из того же локального источника. Начни новый чат с нужным навыком.

04 / КОМАНДА В CHATGPT

Синхронизируй marketplace.

Администратор открывает Admin → Plugins → Marketplaces → Team Agent Kit → Sync now, затем проверяет отчёт синхронизации и версию импортированного плагина.

Новые импорты по умолчанию проверяют обновления ежедневно. Для получения изменений источник должен следовать ветке main; закреплённый commit остаётся на своей версии. Права участников и настройки подключённых сервисов проверяются отдельно.

ПРОВЕРКА

Убедись, что обновление применилось.

  1. Сравни установленную версию с доступной на этой странице: {{VERSION}}.
  2. Проверь наличие четырёх навыков: describe-task, decompose-task, define-dor-dod и review-task.
  3. В новом чате выполни простой запрос на описание задачи по своим требованиям.

Если что-то не работает, укажи клиент, установленную версию, способ подключения и текст ошибки. Для обращения используй обезличенный пример.
