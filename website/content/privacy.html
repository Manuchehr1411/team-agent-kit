Область политики

Эта страница описывает информационный сайт Team Agent Kit на GitHub Pages и текущий пакет с ролями и скиллами. Она не заменяет политики платформ, в которых пользователь запускает ИИ-модель, или самостоятельно подключённых сервисов.

Посещение сайта

Код сайта не содержит форм, аналитики, рекламных трекеров или собственного серверного хранилища. Он не записывает cookies и данные в localStorage. Страницы и стили загружаются с GitHub Pages.

Хостинг обслуживает GitHub. По его документации, при посещении Pages IP-адрес посетителя записывается и хранится для целей безопасности. Порядок такой обработки и сроки определяются GitHub, а не этой библиотекой. См. описание обработки на GitHub Pages и политику GitHub.

Использование ролей и скиллов

Текущий пакет содержит инструкции, шаблоны и учебные примеры. Он не включает собственный MCP-сервер, телеметрию или endpoint издателя для приёма запросов. Сам пакет не отправляет текст задач издателю.

Пользователь передаёт материалы выбранной ИИ-платформе. Если он подключает Jira, Confluence или другой источник, данные могут обрабатываться этой платформой и подключённым сервисом в рамках их настроек и политик. Публичная установка библиотеки не передаёт пользователю доступ к чужим аккаунтам или источникам.

Обращения за поддержкой

Поддержка ведётся через GitHub Issues. При создании обращения GitHub и сопровождающий проекта видят опубликованный текст, вложения и публичные сведения аккаунта автора. Эти сведения используются для ответа, диагностики и развития проекта; публичные обращения также доступны другим посетителям репозитория.

Отдельная база обращений в коде этого проекта не предусмотрена. История Issues может оставаться публичной, пока доступна соответствующая запись; её удаление и обработка запросов выполняются в пределах функций и правил GitHub. Эта страница не устанавливает произвольный срок хранения технических журналов GitHub.

Конфиденциальные отчёты об уязвимостях направляются через private vulnerability reporting GitHub. Их содержание и сведения об авторе доступны GitHub, сопровождающим проекта и участникам приватного отчёта, а не всем посетителям репозитория. Данные используются для проверки и исправления уязвимости; хранение и управление записью осуществляются средствами GitHub. Не включай в отчёт рабочие секреты или реальные клиентские данные.

Контроль и обращения

Можно пользоваться информационным сайтом без создания обращения. Не включай в примеры секреты и реальные клиентские данные. Вопросы об опубликованном обращении или обработке данных направляй через страницу поддержки. Дополнительные средства управления данными аккаунта предоставляет GitHub и выбранная ИИ-платформа.

Изменение состава продукта

Если у проекта появятся собственный сервис, сбор данных или новый канал поддержки, эту политику потребуется обновить до использования соответствующих возможностей.
