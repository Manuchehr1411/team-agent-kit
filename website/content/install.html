01 / CODEX

Добавь каталог и установи пакет.

Нужен установленный Codex с командами управления плагинами. В терминале выполни:

codex plugin marketplace add https://github.com/Manuchehr1411/team-agent-kit.git
codex plugin add team-agent-kit@team-agent-kit

Начни новую сессию. Выбери навык Team Agent Kit через $ или в разделе Plugins. Если команды plugin нет, проверь доступность этой функции в своей версии клиента.

02 / CLAUDE CODE

Установи для своего пользователя.

В терминале с установленным Claude Code выполни:

claude plugin marketplace add https://github.com/Manuchehr1411/team-agent-kit.git
claude plugin install team-agent-kit@team-agent-kit --scope user

Начни новую сессию. Для описания задачи вызови /team-agent-kit:describe-task, для отдельного ревью — /team-agent-kit:review-task. Эта инструкция относится к Claude Code; способы подключения в других продуктах Claude отличаются.

03 / CHATGPT DESKTOP

Подключи локальный источник.

Этот способ предназначен для локальной работы в Work/Codex в поддерживаемом настольном приложении ChatGPT. Доступность marketplace зависит от клиента и настроек аккаунта.

  1. Склонируй репозиторий в удобную папку:
git clone https://github.com/Manuchehr1411/team-agent-kit.git
  1. Открой папку team-agent-kit как локальную рабочую область и перезапусти настольное приложение.
  2. Открой Plugins, выбери источник Team Agent Kit и установи пакет. Каталог уже находится в репозитории; вручную создавать конфигурацию не нужно.
  3. Начни новый локальный чат и выбери нужный навык через @.

Если источник не появился, проверь, что открыта именно папка библиотеки и скопирован скрытый каталог .agents. Установка в настольном приложении не добавляет пакет автоматически во все веб- и мобильные чаты.

04 / КОМАНДА В CHATGPT

Импортируй из GitHub.

Понадобится администратор рабочего пространства с доступной функцией импорта marketplace. Открой Admin → Plugins → Add → Import marketplace и укажи:

Source
https://github.com/Manuchehr1411/team-agent-kit
Path
Оставь пустым: каталог находится в корне репозитория.
Branch, tag, or commit
main — для получения следующих обновлений.

Выполни импорт, проверь его результат и назначь доступ нужным ролям. При запросе авторизации выбери GitHub-аккаунт, который может читать репозиторий.

Плагин будет доступен в этом рабочем пространстве. Импорт не предоставляет участникам доступ к чужим Jira, Confluence и другим источникам.
