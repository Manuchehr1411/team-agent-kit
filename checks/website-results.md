# Проверка сайта GitHub Pages

Фактический локальный прогон: 2026-10-19. Внешняя публикация не выполнялась.

| Проверка | Результат |
| --- | --- |
| `python scripts/build_website.py` | Собраны 7 файлов: четыре страницы, CSS, логотип и JSON с планируемыми URL |
| `python checks/validate_website.py` | 4 страницы, 55 внутренних ссылок и ресурсов; ошибок 0 |
| `python checks/validate.py --yaml` | 103 файла, 4 скилла, 130 локальных ссылок, 11 YAML-проверок; ошибок 0 |
| `python checks/validate_distribution.py` | 39 файлов пакета, 52 ссылки, ZIP и перенос проверены; ошибок 0 |
| `python checks/validate_distribution.py --submission` | Ожидаемый отказ: четыре URL ещё отсутствуют в манифесте до размещения и проверки страниц |
| Workflow YAML | Разобран PyYAML; проверены ручной запуск, основная ветка, разрешения Pages и загрузка только dist/website |
| Локальный HTTP | Главная, support, privacy и terms вернули 200; CSS и SVG загрузились успешно |
| Навигация в браузере | Переходы главная → privacy → terms → support → главная работают |
| Обычное окно | Главная просмотрена визуально: заголовок, кнопки, навигация и стили отображаются |
| Мобильное окно | Override 390×844, доступная ширина документа 375 px; после исправления privacy, terms и support имеют scrollWidth = clientWidth = 375; главная также без горизонтального переполнения |
| Исправление при просмотре | Устранены обрезание заголовка privacy и отсутствие боковых отступов мобильной шапки |
| Текущая модель данных | Статические страницы, без форм, скриптов, аналитики и собственного backend; политика отдельно описывает GitHub Pages и публичные Issues |

Проверка YAML — локальная проверка структуры, не запуск GitHub Actions. HTTP-ответы получены локально, не с github.io. Начальное чтение GitHub показало публичный пустой репозиторий с включёнными Issues и без Pages; это не результат деплоя.

Тексты privacy и terms подготовлены для просмотра издателем. Лицензия репозитория отдельно не выбрана. Нативные клиенты повторно не тестировались из-за добавления сайта: код скиллов не изменялся; история проверки устанавливаемого пакета находится в [distribution-results.md](distribution-results.md).

Публичная доступность четырёх URL, deploy workflow и принятие заявки каталогом пока не проверены. Заполнение ссылок после деплоя не устраняет полученный пользователем отказ skills-only.
