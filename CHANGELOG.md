# История изменений

## 0.2.2 — 2026-10-19

- Добавлены лицензия MIT и пояснение её применения на русском; лицензия включается в ZIP и метаданные всех поддерживаемых форматов.
- Данные издателя приведены к публичному аккаунту Manuchehr1411; подготовлены обновлённые privacy и terms и новая сборка для повторной загрузки.
- Сайт опубликован через GitHub Pages; после проверки четырёх HTTPS-страниц обязательные URL внесены в манифесты. Добавлена инструкция повторной загрузки ZIP без обещания приёма skills-only заявки.

- Подготовлены информационный сайт, поддержка, privacy policy и terms для GitHub Pages в указанном публичном репозитории.
- Добавлены статическая сборка, проверка ссылок и workflow GitHub Pages с ручным запуском; локальная сборка отделена от фактической публикации и доступности URL.
- Зафиксированы окончания строк LF для воспроизводимости файлов и хешей пакета при получении через Git на разных платформах.

## 0.2.1 — 2026-10-19

- Исправлен подзаголовок листинга до ограничения 30 символов; добавлены граничные проверки метаданных.
- Готовность локального пакета отделена от готовности публичной подачи. Зафиксированы полученный отказ skills-only и отсутствие обязательных URL, без выдуманных адресов и MCP-подключений.

## 0.2.0 — 2026-10-19

- Подготовлены устанавливаемый пакет и каталоги для Codex, ChatGPT и Claude Code без внешних подключений.
- Добавлены сборщик с пересчётом ссылок, ZIP, проверка самодостаточности пакета и примеры настроек аккаунта.
- Инструкции установленного пакета загружаются выбранным скиллом; роли и профили сохраняют статус соглашений библиотеки.
- Добавлен сценарий первого запуска без проектного профиля; явный выбор скилла через разные клиенты одинаково применяется на уровне запроса.

- После проверки названий во внешнем трекере уточнено различие категорий библиотеки, отображаемых названий и ID типов трекера. Убрано предположение о фиксированном имени `Subtask` для разработки. Реальные проектные настройки не перенесены в общие скиллы и учебные профили.

## 0.1.0 — 2026-10-19

- Добавлены роли бизнес-аналитика и системного аналитика.
- Добавлены `describe-task`, `decompose-task`, `define-dor-dod`, `review-task`.
- Выделены общие стандарты, формат профилей и правила работы с источниками.
- Добавлены одна команда, два синтетических проекта, примеры и восемь проверочных сценариев.
- Предусмотрены ручное применение профилей, отдельный режим записи в трекер и дальнейшая упаковка в плагин.
